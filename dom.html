Website Structure (DOM)

The Document Object Model (DOM) represents a page as a tree of nodes. Below is the site structure, followed by a live DOM tree of this very page generated by JavaScript.

1. Site structure

  • Adunni Couture website
    • index.html (Home)
    • products.html (Product Showcase)
    • board.html (Board of Trustees)
    • events.html (Upcoming Events)
    • contact.html (Inquiries & Appointments)
    • dom.html (DOM Structure)
    • style.css (external stylesheet, linked by every page)
    • script.js (JavaScript, loaded by every page)

2. Shared page skeleton (same on every page)

document
 └── html
      ├── head
      │    ├── meta (charset, viewport)
      │    ├── title
      │    └── link (style.css)
      └── body
           ├── header.site-header
           │    ├── div.logo
           │    ├── div.tagline
           │    └── nav > ul > li > a  (6 links)
           ├── div.ticker > marquee
           ├── main  (page-specific content)
           ├── footer
           └── script (script.js)

    4. Accessing the DOM with JavaScript

    document.getElementById("quote")          // find one element
document.querySelectorAll("nav a")         // find many
element.textContent = "New text"           // change content
element.classList.add("active")            // change styling
parent.appendChild(child)                  // change structure
